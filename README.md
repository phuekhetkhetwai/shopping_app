About the App

This is a simple shopping website. Users can view products, add products to the cart, and place orders.

The website includes:

Login – Users can log in to the website.

Products – Users can view product details.

Cart – Users can add and manage products in the cart.

Checkout – Users can enter their information and place an order.

Confirmation – Users can see their order confirmation.

There is also an Admin section for managing the website.The admin can manage the shopping website.

Manage Products – Add, edit, and delete products.

Manage Orders – View and manage customer orders.

Manage Users – View and manage user accounts.

This project helps us learn how a basic online shopping website and admin system work.
